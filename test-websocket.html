💬 채팅 API 테스트 도구

⚙️ 설정

🔌 실시간 채팅 (WebSocket)

🔴 연결 안됨

room.join - 채팅방 입장

message.send - 메시지 전송 (실시간)

📡 채팅방 관리 (REST API)

POST /chats/clubs/{clubId}/room - 클럽 채팅방 입장 (그룹)

ACTIVE 클럽 멤버만 입장(멱등). 최초 입장 시 "…님이 입장했습니다" SYSTEM 메시지가 나갑니다. 성공하면 chatRoomId가 위/아래 입력칸에 자동 채워집니다.

POST /chats/rooms - 새 채팅방 생성 (1:1)

상대방과 처음 만날 때 사용합니다.

GET /chats/rooms - 내 채팅방 목록

로그인 후 내가 참여 중인 채팅방을 보여줍니다.

GET /chats/rooms/{id} - 채팅방 상세

GET /chats/rooms/{id}/messages - 과거 메시지 조회

채팅방 입장 시 이전 메시지들을 받아옵니다.

PATCH /chats/rooms/{chatRoomId}/read - 채팅방 읽음 처리 (방 단위 커서)

내 읽음 커서(lastReadAt)를 현재 시각으로 전진. 기존 메시지 단위 read를 대체합니다. (DIRECT/CLUB 공통)

PATCH /chats/messages/{messageId} - 메시지 전송취소

DIRECT: 상대 미열람 시만(읽힘 409 CHAT-005). CLUB: 항상 차단(409 CHAT-006).

🟢 활동중 사용자 (REST)

GET /users/active - 현재 활동중 사용자 조회

내 지역(또는 areaCode) 기준 현재 활동중 유저. 데이터 소스는 소켓 presence + 주기적 ping이라 연결 후 ping(자동 ping 권장)을 보내고 있어야 뜹니다. 본인은 결과에서 제외되므로, 같은 지역 다른 유저가 접속+ping 중이어야 목록이 채워집니다(탭 2개로 테스트).
